# Кітапхана ақпараттық жүйесі

## Жоба туралы
Бұл жоба кітапхана жұмысын ақпараттық жүйе арқылы ұйымдастыруға арналған. Жоба аясында кітапхана жүйесіне қойылатын талаптар мен қолдану жағдайлары сипатталады.

## Мақсаты
Кітапханадағы кітаптар мен оқырмандар туралы ақпаратты басқару жұмысын жеңілдету.

## Зертханалық жұмыстар
- 1-зертханалық жұмыс
- 2-зертханалық жұмыс
- 3 және 4-зертханалық жұмыстар

## Құжаттар
Зертханалық жұмыстардың файлдары осы репозиторийде сақталған.
Жоба GitHub Desktop арқылы нұсқаланады.
